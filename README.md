# Advent of Code 2025

My solutions to [Advent of Code 2025](https://adventofcode.com/2025), written in Python.

## Layout

One folder per day, each containing:

- `main.py` — the solution
- `input.txt` — my puzzle input (not tracked, see below)
- `example.txt` — the sample input from the puzzle (not tracked)

## Running a solution

    cd <day>
    python main.py

Puzzle inputs are ignored by git, so clone this repo and drop your own
`input.txt` into the day folder you want to run.
